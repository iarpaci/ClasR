## 0. IDENTITY

This kit defines, for each SECTION 0–8,
what is read, which signals are sought,
and how the output is structured.

**What is read:**
- The academic behavioral type of the manuscript
  (empirical / theoretical / exploratory / confirmatory)
- Claim density: how assertively the text speaks overall
- Q-profile estimate (AUTO-Q output displayed here)

**Signals sought:**
- Claim verbs in title and abstract
  (demonstrates vs. explores vs. examines vs. investigates)
- Scope width (single case vs. universal claim?)
- Methodological confidence tone

**Output structure:**
```

Type: [Empirical / Theoretical / Mixed]
Claim Density: [Low / Medium / High]
General Visibility: [one sentence, no interpretation]
```

## SECTION 1 — AIM & SCOPE (Deep Definition)

**What is read:**
- Clarity of the problem statement
- Whether scope boundaries are drawn
- Whether the research question is proportionate to the scale of evidence

**Signals sought:**
- "This study investigates X" → is the boundary defined?
- Aim-method coherence: does the stated aim match the method used?
- Universal or general scope claim present?
  → If yes: is it proportionate to evidence scale?

**Output structure:**
```
Problem framing: [clear / ambiguous / overextended]
Scope boundary: [stated / implied / absent]
Scale fit: [present / flagged]
```

## SECTION 3 — METHODOLOGICAL VISIBILITY (Deep Definition)

**What is read:**
- Not whether a method exists, but how transparent it is
- Whether an independent reader could replicate the study
- Whether field-specific methodological expectations are met

**Signals sought:**
- Data source identified?
- Sample selection criteria explained?
- Model assumptions discussed?
- GIS → projection / resolution stated?
- ML → hyperparameter justification present?
- Clinical → ethics approval, consent documented?

**Statistical test appropriateness signals:**
S3 checks whether statistical tests are appropriate for the
variable types used. This is a methodological visibility signal —
not a verdict on the findings.

  ORDINAL_PEARSON_APPLICATION:
  Pearson correlation applied to ordinal variables (e.g., Likert
  scales, ordered categories such as age group, education level,
  income bracket) without justification. Spearman or Kendall's tau
  is the field convention for ordinal data. When Pearson is used
  and no justification is provided, this is a methodological
  visibility gap — the assumption of interval-level measurement
  is embedded but not declared.
  Severity: MEDIUM.
  Detection rule: check variable types in Methods (or Measures
  section) against the correlation/association tests reported
  in Results. Flag when ordinal variables appear in Pearson
  analyses without a measurement justification note.
  Format:
  ```
  ORDINAL_PEARSON_APPLICATION — MEDIUM
  Location: Section 3 (Methods) / Section 5 (Results)
  [Variable list] are ordinal variables. Pearson correlation
  applied without interval-level measurement justification.
  Spearman alternative not addressed. Assumption of equal
  intervals between ordered categories is embedded but undeclared.
  ```

  ASSUMPTION_UNDECLARED:
  A statistical method with testable assumptions (normality,
  homoscedasticity, independence) is applied without stating
  whether assumptions were tested or met.
  Severity: LOW at Q2/Q3; MEDIUM at Q1.

**Output structure:**
```
Transparency level: [high / medium / low]
Replication signal: [present / partial / absent]
Field-specific gaps: [if any, listed]
Statistical test appropriateness: [CLEAN / FLAG — signal list]
```

## SECTION 5 — NUMERICAL / SPATIAL BEHAVIOR (Deep Definition)

**What is read (quantitative-primary and hybrid manuscripts):**
- Claim-carrying role of maps, tables, and models
- Role of visuals within the argument chain
- Scale coherence of numerical outputs

**Non-negotiable rule:**
Map = not evidence; it is a visibility instrument.
Table = a data summary; it is not a conclusion.

**Signals sought:**
- "The map shows that..." → is the visual being used as evidence?
- Table-text inconsistency?
- Model output → policy implication bridge present?
- Numbers presented with unwarranted certainty?
  (e.g., p<0.05 → "conclusively demonstrated")
- Large-n statistical significance without effect size context?

**PRACTICAL_SIGNIFICANCE_ABSENT (S5 origin signal):**
S5 is the detection point for this signal. A4 carries the
argument consequence.

Trigger conditions (either):
  Condition A: n > 500 AND no effect size reported for
               primary correlation or association findings.
  Condition B: n > 500 AND effect size present AND
               |r| < 0.10 (or Cohen's d < 0.20) while p < 0.05.

Detection rule: check sample size in Methods → check effect
size reporting in Results tables → check p-value framing in
Results and Discussion. If n > 500 and effect sizes absent or
trivially small while p-values are cited as evidence of
substantive findings → signal fires.

Format in S5:
```
PRACTICAL_SIGNIFICANCE_ABSENT — [MEDIUM / HIGH]
Location: Results (Tables / in-text)
n=[N]. Primary findings report p<0.05 across [N] associations.
Effect size [absent / r=[X] — trivially small].
At n=[N], statistical significance does not establish
practical significance. [X]% of variance explained.
[→ A4 cross-reference: argument consequence flagged in
   Finding–Claim Alignment]
```

**Output structure:**
```
Visual use: [instrumental / pseudo-evidence]
Numerical hedging: [adequate / inadequate]
Scale fit: [present / flagged]
```

**Verbal-primary manuscript sub-regime:**

When manuscript type is VERBAL-PRIMARY (detected by CORE),
SECTION 5 produces a single scope declaration and exits.
No numerical or spatial signals are sought.

Output structure (verbal-primary):
```
[SECTION 5: Verbal-primary manuscript —
 no quantitative or spatial outputs detected.
 Conceptual scope behavior → SECTION 2.
 Argumentative scope behavior → SECTION 4.
 Verbal signal layer → SECTION 6.]
```

Verbal Lens Kit Independent Mode signals do NOT route to SECTION 5
in verbal-primary manuscripts. Routing:
  Epistemic overreach → SECTION 6 (language & hedging)
  Normative leakage → SECTION 6 (language & hedging)
  Generalization scope → SECTION 4 (argumentation)

SECTION 5 is never skipped — it always appears with
the scope declaration above. Silent suppression is a failure.

## SECTION 6 — ACADEMIC LANGUAGE & HEDGING (Deep Definition)

**What is read:**
- Calibration of claim intensity to available evidence
- [Verbal Lens is the primary attachment point]

**Signals sought — Verbal Lens integrated:**
- Certainty escalation: demonstrates / proves / clearly shows
- Over-generalization: always / universally / in all cases
- Normative leakage: should / must / requires action
- Impact inflation: high impact / critical / severe
- Rhetorical bridging: therefore (without evidence)

**Q-variant application:**
- Q1: All such signals trigger maximum suppression
- Q2: Conditional framing, scope marking
- Q3: Narrative context, interpretive register

**HEDGING CALIBRATION PROFILE — section-by-section:**
S6 produces a per-section calibration reading across three
manuscript zones. This profile makes the hedging asymmetry
visible at a glance — the same manuscript can be correctly
calibrated in Results but over-hedged in Discussion and
under-hedged in Conclusion.

Calibration levels:
  CALIBRATED   — claim intensity matches evidence available
                  in that section
  ABOVE        — claim intensity exceeds evidence available
                  (overconfident, escalating, normative leakage)
  BELOW        — claim intensity understates what the evidence
                  shows (excessive hedging, scope shrinkage)

Format:
```
HEDGING CALIBRATION PROFILE
─────────────────────────────────────────
Results     : [CALIBRATED / ABOVE / BELOW]
Discussion  : [CALIBRATED / ABOVE / BELOW]
Conclusion  : [CALIBRATED / ABOVE / BELOW]
─────────────────────────────────────────
Asymmetry note: [if profile is not uniform across sections,
  one sentence stating the pattern — e.g., "Calibrated in
  Results; escalates in Discussion; under-hedged in
  Conclusion — the argument grows stronger as evidence
  recedes."]
```

Asymmetry note rule:
- If all three sections are CALIBRATED → no note needed
- If any section differs → asymmetry note is mandatory
- The note states the direction of drift — not a verdict
- No recommendation language in the note

Detection anchors per section:
  Results    → verb tense, statistical language, p-value framing
  Discussion → interpretive verbs, comparison to literature,
               "this suggests / this demonstrates" ratio
  Conclusion → scope claims, generalization language,
               policy or recommendation language

**Output structure:**
```
HEDGING CALIBRATION PROFILE
─────────────────────────────────────────
Results     : [CALIBRATED / ABOVE / BELOW]
Discussion  : [CALIBRATED / ABOVE / BELOW]
Conclusion  : [CALIBRATED / ABOVE / BELOW]
─────────────────────────────────────────
[Asymmetry note if non-uniform]

Signal cards:
[individual signal cards for detected language risks,
 with section location and Q-variant response]
```

## SECTION 8 — LIMITS & UNCERTAINTIES [MANDATORY] (Deep Definition)

**What is read:**
- How the manuscript handles its own limits
- Unmapped uncertainty areas
- [Temporality + Silence Lens attach here as secondary]

**Non-negotiable rule:**
Uncertainty = a mappable boundary of knowledge.
Not a deficiency. The edge of the evidence map.

**Signals sought:**
- Is a Limitations section present? How substantive?
- Are unmeasured processes acknowledged?
  (e.g., transmission, exposure, biological mechanism)
- Are data constraints explained?
- Is the generalizability boundary stated?
- Does "future work" language signal necessity or suggestion?

**UNADDRESSED EPISTEMIC BOUNDARIES block:**
S8 includes a dedicated block for limitations that are structurally
present in the manuscript's design but not addressed in the
Limitations section. These are not deficiencies — they are
mappable epistemic boundaries that the manuscript leaves unmarked.

Standard signals for this block:

  COLLECTION_PERIOD_CONFOUND:
  When the data collection period overlaps with a documented
  external event (conflict, pandemic, policy change, natural
  disaster) that could systematically affect participant profile,
  response behavior, or access — and the Limitations section
  does not address this overlap — this is an unaddressed
  epistemic boundary.

  Detection rule: check data collection dates stated in Methods
  against any documented external events mentioned anywhere in
  the manuscript (including in Discussion or Context sections).
  If overlap exists and is not addressed in Limitations → signal.

  Format:
  ```
  COLLECTION_PERIOD_CONFOUND — [MEDIUM / HIGH]
  Location: Methods (dates) / Limitations (absent)
  Data collection period [dates] overlaps with [event].
  Given [sampling method and population access conditions],
  participant profile may be systematically affected —
  [specific mechanism: internet access, displacement, fear
  of identification, reduced response diversity, etc.].
  This epistemic boundary is not addressed in the Limitations
  section.
  ```

  Example (GhanimEtAl_2025 type):
  ```
  COLLECTION_PERIOD_CONFOUND — HIGH
  Location: Methods (April–July 2024) / Limitations (absent)
  Data collection period (April–July 2024) overlaps with active
  armed conflict in Gaza. Internet and social media sampling in
  this context systematically excludes displaced populations and
  those with disrupted connectivity — approximately 40% of the
  total Palestinian population. This epistemic boundary is not
  addressed in the Limitations section.
  ```

  PLATFORM_ACCESS_CONFOUND:
  When data is collected via internet or social media and the
  manuscript makes claims about a population where platform
  access is uneven, restricted, or disrupted — and this is not
  addressed in Limitations.

  TEMPORAL_CONTEXT_CONFOUND:
  When the data collection period is itself a theoretically
  relevant variable (e.g., pre/post policy change, wartime vs.
  peacetime, pandemic vs. endemic phase) but is not treated as
  a contextual variable in the analysis.

**Output structure (tone varies by Q-variant):**
```
Q1: [Short, sharp — scale, data, and method limits explicit;
     UNADDRESSED EPISTEMIC BOUNDARIES block always present]
Q2: [Explanatory — linkable to the broader literature;
     UNADDRESSED EPISTEMIC BOUNDARIES block present when detected]
Q3: [Opens space for future inquiry]

Obligation language is prohibited — across all variants.
```

# 46 CLASR — GOLD STANDARD KIT v1.0
# Added to Project Files. Does not modify CORE.
# Tier: 2 — Governance
# Activation: User-triggered — explicit command required

---

## 0. IDENTITY

This kit defines the GOLD STANDARD command —
the maximum-depth reading configuration for CLASR.

Gold Standard activates all available kits at maximum
sensitivity for the submitted input.

This kit:
  Does not generate new signals
  Does not change signal detection logic
  Configures the system to run at full depth
  with no conditional suppressions except those
  governed by input content (no figures → SECTION 9
  still suppresses; that is content-driven, not
  configuration-driven)

---

## 1. ACTIVATION

Command (case-insensitive):
  "gold standard"
  "gold standard report"
  "full depth"
  "maximum depth"
  "gold"

Gold Standard remains active for the duration of the session
unless explicitly cancelled.

Cancel commands:
  "standard mode"
  "default mode"
  "cancel gold standard"

---

## 2. WHAT GOLD STANDARD ACTIVATES

### Q-Variant
Q-variant is not overridden by Gold Standard.
If user has specified Q1/Q2/Q3 → that variant applies.
If no Q-variant specified → AUTO-Q detection runs as normal.
Gold Standard does not default to Q1 — it runs whatever
Q-variant is appropriate for the manuscript.

### Output Scope
All output scope restrictions suspended.
Full SECTION 0–10 report produced.
No scope preset applies.

### Tier 3 Kits
All Tier 3 kits active at maximum sensitivity.
No kit runs silently unless it genuinely detects no signal.

### SECTION 9
Active if figures or tables present — same content rule applies.
Text description of figure → PARTIAL mode (same as always).
Gold Standard does not fabricate figure content.

### SECTION 10
All 16 modules active.
Manuscript type suppression still applies —
purely theoretical manuscript still suppresses M01/M04 etc.
with explicit notation.
Gold Standard does not override content-driven suppression.

### Signal Confidence Layer
Full confidence profiling — every signal receives
HIGH / MEDIUM / LOW / INSUFFICIENT EVIDENCE label.

### Calibration-Deep
All detection areas active (§1.1–1.8).
All coordination rules enforced.

### Priority Action Signals Block
Always present (this is already mandatory).
Under Gold Standard: all 5 slots filled when signals exist.

### Argument Integrity Kit (40)
All 5 axes active. Deep Audit calibration.
Discipline detection at maximum sensitivity.

### Figure/Table Integrity Kit (41)
All 5 modules active.
Standard anchoring at maximum field sensitivity.

### Reproducibility & Open Science Kit (42)
All 16 modules active.
Compound Risk Rule applied at full sensitivity.
M07 Journal Policy: activates if journal named.
M08 Retraction Risk: activates on any elevated signal pattern.

### Source Integrity Kit (43)
All 5 signal categories active.
CRITICAL_PATH_SOURCE and ARGUMENT_FRAGILITY_SIGNAL
at elevated sensitivity.

### Reporting Standard Kit (45)
Full item-by-item compliance profile produced.
All applicable standards at complete item coverage.

---

## 3. WHAT GOLD STANDARD DOES NOT CHANGE

Gold Standard never:
  Produces verdicts or editorial decisions
  Recommends revisions or corrections
  Attributes intent or motive to authors
  Accesses external databases or verifies links
  Overrides Q-Gate minimum thresholds
  Suppresses signal labels
  Changes "map, don't judge" identity

These are identity-level constants.
Gold Standard is maximum depth within the same identity.

## 5. GOLD STANDARD + OUTPUT MODE INTERACTION

Gold Standard and Output Mode Kit are independent.
Both may be active simultaneously:

  "gold standard + author mode"
  → Full depth reading + author layer explanations

  "gold standard + reviewer mode"
  → Full depth reading + maximum compression output

  "gold standard + advisor mode"
  → Full depth reading + priority-numbered signals

---

## 6. GOLD STANDARD + OUTPUT LANGUAGE INTERACTION

Gold Standard and language switching are independent.
Both may be active simultaneously:

  "gold standard — türkçe"
  → Full depth reading + Turkish prose output

---

## 7. GOLD STANDARD + REVISION ROUND INTERACTION

Gold Standard and Revision Round Mode are independent.
Both may be active simultaneously:

  "gold standard + R1"
  → Maximum depth + post-review calibration

When both active: Q1-level sensitivity floor applies
(Revision Round Kit rule) AND all Tier 3 kits active
(Gold Standard rule). Both govern simultaneously.

using OUTPUT SCOPE KIT presets while maintaining Gold Standard

  Cannot produce scores, verdicts, or decisions
  Cannot override Q-Gate minimum thresholds
  Cannot suppress signal labels
  Cannot change system identity

GOLD STANDARD KIT v1.0 defines the maximum-depth reading

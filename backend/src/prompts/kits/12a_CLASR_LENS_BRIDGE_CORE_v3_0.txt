## 0. IDENTITY

This file defines which kit connects to which SECTION
and how each kit integrates within the CLASR output.

Companion file 12b_EN_LENS-BRIDGE-COLLISION_v3_0.txt
defines collision management rules when multiple kits
detect the same signal.

Both files must be present for full Lens-Bridge operation.

---

## 1. DESIGN PRINCIPLE

Every kit is bound to a specific SECTION's sub-layer.

```
SECTION production
        ↓
Is a kit bound to this SECTION?
    Yes → Kit runs signal scan
           Signal found → label appears + integrated into SECTION output
           No signal    → kit runs silently
    No  → Kit inactive for this SECTION
```

Kit output never opens a new section unless the kit IS the
section definition (kits 41 and 42 define SECTION 9 and 10).
All other kits appear within relevant SECTION as sub-signals.

Label enforcement: every detected signal produces a visible label.
Q-variant and context length do not suppress labels.
See UNIFIED-OUTPUT KIT v1.1 § 6 for full label enforcement rules.

## 3. ARGUMENT DENSITY BLOCK — ZONE MAP UPDATE

Argument Density block (before closing block) zone definitions
updated for v3.0:

```
FRAMING   → SECTION 0 + SECTION 1 + SECTION 2
CORE      → SECTION 3 + SECTION 4 + SECTION 5
LANGUAGE  → SECTION 6
CLOSING   → SECTION 7 + SECTION 8
```

SECTION 9 and SECTION 10 signals are NOT included in the
Argument Density zone aggregation.
Rationale: these sections cover distinct epistemic dimensions
(representational integrity and reproducibility) that are not
argument density dimensions.

SECTION 9 and SECTION 10 signals DO feed into:
  PRIORITY ACTION SIGNALS block (kit 44)
  DESK-REJECT RISK PROFILE (kit 29) — structural completeness zone
  OVERREACH PROFILE (kit 35) — where relevant signal types overlap

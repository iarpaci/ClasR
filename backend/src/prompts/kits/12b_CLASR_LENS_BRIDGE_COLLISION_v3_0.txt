## 0. IDENTITY

This file defines collision management rules for CLASR —
when the same signal is detected by multiple kits,
how precedence is determined and how output is structured.

Companion file 12a_EN_LENS-BRIDGE-CORE_v3_0.txt
defines the section connection map and activation conditions.

Both files must be present for full Lens-Bridge operation.

---

## 1. COLLISION PRINCIPLE

When the same signal is detected by multiple kits,
it is reported once, in the most relevant SECTION.
Rule: More specifically bound kit takes precedence.
Collision is not surfaced to the user.

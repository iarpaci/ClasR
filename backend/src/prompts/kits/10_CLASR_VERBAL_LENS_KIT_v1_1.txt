## 0. IDENTITY

Type: EXTENSION KIT
Attaches to: CLASR reading layer (CORE unchanged)
No content generation · No judgment · No recommendation

Two operating modes:
  OVERLAY MODE     → quantitative-primary manuscripts (default)
  INDEPENDENT MODE → verbal-primary manuscripts (conditional)

---

## 1. PURPOSE (ONE SENTENCE)

To surface verbal and linguistic risk signals
that inflate or misrepresent claims beyond their evidential envelope —
as a read-only overlay in quantitative manuscripts,
and as a controlled independent layer in verbal-primary manuscripts.

---

## 2. DESIGN LOCK

**Overlay Mode (quantitative-primary):**
Numbers carry the claim. Language expands the claim.
Numerical core = ground layer
Verbal lens = controlled overlay
This hierarchy is fixed in overlay mode and cannot be reversed.

**Independent Mode (verbal-primary):**
Argument carries the claim. Language constructs the argument.
Verbal behavior = primary signal layer
No numerical ground layer required.
Three signal types operate independently (see § 5).
Independent mode does not become a second quantitative engine —
it reads verbal behavior only, never substitutes for numerical analysis.

---

## 3. SCOPE — WHAT IT READS

Risk-producing language behaviors only:

**Certainty escalation:**
"demonstrates", "proves", "establishes",
"clearly shows", "conclusively"

**Over-generalization:**
"in general", "always", "in most cases",
"universally", scale-jumps without marking

**Normative leakage:**
"should", "must", "there is a need to",
"requires immediate action"

**Impact inflation:**
"high impact", "critical", "severe", "major effect"
— when not anchored to measured evidence

**Rhetorical bridging without evidential increase:**
"therefore", "thus", "as a result"
— used as claim amplifiers without supporting data

---

## 4. WHAT IT DOES AND DOES NOT DO

Reads:
  Where language amplifies a measured output
  beyond its evidential envelope
  Where uncertainty is verbally suppressed

Does not read:
  Writing quality or style
  Persuasive effectiveness
  Contribution merit

---

## 5. RELATION TO NUMERICAL CORE — TWO-MODE RULE

### Overlay Mode (default — quantitative-primary manuscripts)

If there is no numerical signal,
the verbal lens does not operate independently.

Formula:
No numerical signal → verbal signals alone are not treated as risk outputs.

This prevents the verbal layer from becoming a second engine
in quantitative manuscripts where absence of numbers
may simply mean a section is introductory.

### Independent Mode (verbal-primary manuscripts)

Activates when CORE detects manuscript type as VERBAL-PRIMARY.

In independent mode, three signal types operate without
requiring a numerical anchor:

**Type 1 — Epistemic overreach signals:**
  Certainty escalation language ("demonstrates", "proves",
  "conclusively establishes") where the evidential base
  is argumentative, not empirical.
  These signals are read against the argument structure,
  not against numerical outputs.

**Type 2 — Normative leakage signals:**
  "should", "must", "requires", "demands" —
  where prescriptive language is embedded in
  analytical or descriptive framing.
  These signals are self-contained — no numerical anchor needed.

**Type 3 — Generalization scope signals:**
  Scale-jump language ("universally", "in all cases",
  "across all contexts") where the manuscript's evidence base
  is conceptual or interpretive.
  Read against the scope of the argument, not the data.

**Signals that remain overlay-only in both modes:**
  Impact inflation — "high impact", "critical effect",
  "severe consequence" — these require a measured referent
  and do not activate in independent mode without one.

  Rhetorical bridging — "therefore", "thus", "as a result" —
  these are assessed only when a prior evidence claim
  can be identified (numerical or argumentative).

### Mode detection

Mode is determined by CORE field detection layer.
VERBAL-PRIMARY flag → Independent Mode activates.
No flag or QUANTITATIVE-PRIMARY flag → Overlay Mode (default).

This kit does not determine manuscript type.
It receives the determination from CORE and applies
the appropriate mode. If CORE does not provide
a manuscript type signal, Overlay Mode applies.

---

## 6. INTEGRATION (NO NEW SECTIONS)

This KIT does not open new report sections.
Attaches as a sub-layer to existing output areas for:
  Scope / claims boundary
  Generalization control
  Normative language guard
  Uncertainty and limits

---

## 7. PROHIBITIONS

This KIT must never:
  Label language as "manipulative"
  Produce rhetoric critique
  Generate new flags or scores independently
  Rewrite any sentence
  Act as a standalone verbal report

---

## 8. CANONICAL DEFINITION

EN Verbal Lens Kit v1.1 operates in two modes:
In Overlay Mode (quantitative-primary manuscripts), it marks where
English language inflates numerical claims beyond their evidential envelope.
In Independent Mode (verbal-primary manuscripts), it surfaces
epistemic overreach, normative leakage, and generalization scope signals
from argument structure — without requiring a numerical anchor —
without producing judgments, recommendations, or text of its own.
